# Monte-Carlo Sharm — redesign demo

A one-page redesign concept for [montecarlosharm.com](https://www.montecarlosharm.com/), by **Sociofy**.

Open `index.html` in a browser — no build step.

## What's in it
- **Horizon hero**: the resort photo opens from a single gold line (the Red Sea horizon), with a working date/guest booking bar that hands off to the hotel's booking page.
- **"Choose your view" room explorer**: all 9 room types, filterable by Sea / Pool / Garden / Families / Royal, keyboard-navigable.
- **Dining as a menu card** for the six restaurants.
- **Royal Monte-Carlo** adults-only wing in the brand's gold and brown.
- **Distance scale**: nearby places plotted by real minutes from the hotel gate.
- Mobile layout with a sticky "Book a stay" button, reduced-motion support, visible focus states.

## Built with
- Skills: Anthropic `frontend-design`, VectorLab `anti-slop`, Firecrawl (content and brand extraction from the live site)
- Open source: [Lenis](https://github.com/darkroomengineering/lenis) smooth scroll, Google Fonts (Bodoni Moda + Figtree)
- Plain HTML/CSS/JS in one file. All photos are the hotel's own, loaded from its current site.
